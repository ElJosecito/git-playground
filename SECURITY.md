# Política de seguridad

Git Playground corre completamente en tu navegador: no hay servidor, cuentas ni datos que salgan de tu equipo. Lo único que se guarda es tu progreso, en el `localStorage` del navegador.

Aun así, si encuentras un problema de seguridad (por ejemplo, una forma de inyectar HTML o scripts a través de nombres de archivo, mensajes de commit o comentarios de un pull request), te pedimos que **no lo publiques en un issue**.

## Cómo reportarlo

Usa el reporte privado de vulnerabilidades de GitHub: en el repositorio, ve a **Security → Report a vulnerability**. Incluye los pasos para reproducirlo y, si puedes, los comandos exactos.

Te responderemos lo antes posible y te avisaremos cuando esté resuelto. Si quieres, te daremos el crédito en la nota del arreglo.

## Versiones soportadas

Solo la versión publicada en `main` (la que está en GitHub Pages) recibe arreglos.
